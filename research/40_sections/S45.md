## 45. Client Clarification Questionnaire

This is the list of things the blueprint cannot decide for Atha Group. Each question is self-contained: it can be read and answered on its own, without reading any other part of this document.

**How to use it.** Answer in the right-hand column. Where a question offers options, circling or naming one is enough. Where you do not yet know, write "to be confirmed by" and a name and date — an owned gap is more useful to the build than a guess. Questions marked **BLOCKING** must be answered before the proof of concept is built, because the answer changes what is built rather than how it behaves.

**The eight blocking answers, if nothing else is answered:** Q1, Q9, Q13, Q18, Q28, Q44, Q51 and Q56.
